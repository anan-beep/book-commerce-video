# 视觉、素材与分镜

## 1. 先定统一风格

根据书的情绪和受众选择风格。当前模板可使用“写实人物、低饱和度、暗色电影感、暖色实景光”，但不要把它套到所有选题。

每组素材都遵守：

- 竖屏构图完整，提前避开右侧互动区和底部账号、标题、进度条区域；
- 图片中不生成字幕、书名、水印、品牌文字或未经核实的界面；
- 人物身份、地区和年龄以用户确认的信息为准，不能拿西方面孔冒充中国人；
- 相邻两张不重复同一景别和同一视角；
- 先做一张代表性样图让用户确认，再批量生成。

## 2. 设计视觉节奏

整组正文按以下节奏编排：

1. 建立空间：全景或中远景，让观众理解人物处境；
2. 靠近情绪：中景或近景，看见表情和压力；
3. 观察细节：特写手、手机、账单、书页、时钟等证据；
4. 拉开距离：重新看人与环境的关系；
5. 转折：光线、动作或构图发生明确变化；
6. 收束：画面稳定，为书封、结论或适用人群留空间。

每张图记录叙事功能、景别、视角、构图、对应文案和预计持续时间。

## 3. 开场与书封轮播

当前模板：

- 约 4–5 秒全屏文字 MG 开场，包含主标题、副标题和强识别书名；
- 6–8 张书封按节奏硬切；
- 最后一拍切到本期目标书封并适当停留；
- 轮播使用短促点击、whoosh 或 riser，正文使用短交叉溶解或淡入淡出。

若使用 Pexels 开场视频，选择竖屏构图完整、运动自然、中下部有字幕空间、无明显品牌和水印的素材。用户一旦决定删除它，就把它从时间线依赖中移除；素材池里保留的离线文件不影响成片。

## 4. 正文静态图动效

交替使用：

- 缓慢推进；
- 缓慢拉远；
- 轻微上移；
- 轻微下移；
- 重点句使用短促推进后稳定。

不要连续多张使用同方向、同幅度。只看到关键帧参数不算完成，必须连续播放并对比镜头起点、中点和终点。

## 5. 文件与关联

- 用 `01-...`、`02-...` 等稳定文件名保存封面和正文素材；
- 开场、轮播、正文、配音、音乐、音效分目录存放；
- 记录每个文件是否实际进入时间线。

跨浏览器或重新打开项目时，如果出现黑底文字、书封消失或“待关联文件”，在媒体面板按文件名扫描素材目录重新关联。只有时间线实际使用的离线媒体会阻塞交付。
