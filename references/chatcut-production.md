# ChatCut 时间线制作

## 1. 工作方式

使用 Hosted ChatCut MCP 直接创建和编辑项目，不调用 ChatCut 编辑器里的 AI Agent。开始前读取 `$chatcut:chatcut-plugin-basics`，再根据需要读取素材导入、配音、导出和验收 Skill。

这些 Skill 和工具由 ChatCut 插件提供，不随本仓库分发。按当前工具说明检查授权和可用能力，不猜测工具名称、参数或费用。没有可用工具时交付制作说明，不能声称已经创建时间线。

默认工程规格：

- 1080×1920，30 fps；
- V1：开场、书封轮播、正文画面；
- A1：配音，作为时间轴基准；
- A2：BGM，自动压低，当前模板参考值约为 -12.5 dB；
- A3/A4：轮播点击、whoosh、riser 等音效；
- 一套中文原文和一套英文译文字幕，共用对应语义时间区间。

不要把具体项目 ID、素材 ID 或某台机器的绝对路径写入 Skill。

## 2. 配音

音色未定时，先用同一小段文案生成 4 个短试听，用户选择后再制作正式配音。当前模板可从 1.25 倍速开始试听。

默认按自然语义段生成，但要保持同一音色、参数和响度。若用户明确要求“一整段一次性合成一整条音频”，必须单次整段生成，不能分句拼接。

以最终音频的实际时长和词／短语级时间为准安排画面与字幕。音频被裁剪、替换或再次变速后，旧对齐立即失效，必须重新生成。

## 3. 推荐组装顺序

1. 确认目标项目和画布；
2. 导入并关联本期实际使用的素材；
3. 先放最终配音，锁定总时长；
4. 按配音安排 V1：书封轮播硬切，正文短交叉溶解或淡入淡出；
5. 添加 BGM 与轮播音效，确保人声始终清晰；
6. 创建双语字幕；
7. 给正文静态图添加交替动效；
8. 一个阶段整体稳定后再刷新一次字幕，避免每个小改动都触发全局重算。

## 4. 双语字幕规范

当前模板参考：

- 中文主字幕：约 64 px、700 字重、白色、黑色描边或阴影、单行，建议约 13 个汉字以内；
- 英文辅字幕：约 30 px、500 字重、浅灰色、较细描边、单行，可使用更宽文本框；
- 中文在上，英文在下，间距固定；
- 两行整体放在画面高度约 62%–72% 的安全带，靠近平台评论与五角星图标所在横向区域，但不能遮脸和关键信息。

“单行”不是机械按字数切断。必须保留完整语义词组，例如“扎心”不能拆成“扎／心”，“把所有时间都卖掉”不要切成失去主谓或动宾关系的碎片。

默认显示字幕去掉逗号与句末句号，保留 `1.25` 等小数点；仅修改显示文本，配音和对齐原文保留。深色底板贴合每一行可见文字宽度。字体、字号和安全带属于模板参考，按实际画面与平台预览调整。

英文覆盖率必须是 100%。中文重新分段后，用精确增量修复同步更新英文，不要默认全部重做。

## 5. 局部字幕不同步

当某一句晚于配音出现：

1. 读取该时间范围和对应词级时间；
2. 比较前一字幕结束、目标字幕开始和目标词实际开始；
3. 重置这一个自定义字幕卡片；
4. 必要时合并相邻自动字幕卡片；
5. 不全局平移整条字幕；
6. 预览目标句前后相邻画面并听音确认。

## 6. 预览浏览器

遵循用户本次明确指定的浏览器偏好。若用户要求用 Chrome 查看剪辑预览，使用干净的编辑器 URL 打开同一项目。不要因为内置预览窗口小，就直接断言关键帧没有生效；动效判断仍以连续播放和导出样片为准。
