# 验收清单

按“工程结构 → 关键帧 → 连续播放 → 平台预览”四层检查。

## 1. 工程结构

- 画布为 9:16，分辨率、帧率和总时长正确；
- 时间线没有黑场或意外空隙；
- 配音连续，BGM 不盖住人声；
- 时间线使用的图片和视频全部在线；
- 媒体池中未使用的离线素材可以保留，不作为阻塞项。

## 2. 开场、轮播与正文动效

- 检查第 0 帧、入场中点、标题揭示和最终书封；
- 轮播必须看见真实书封，不能只剩黑底文字；
- 连续播放轮播，确认硬切和音效卡点；
- 正文静态图逐段比较起点、中点、终点，确认推进、拉远或位移肉眼可见；
- 放大和位移后的画面仍在安全裁切范围内。

## 3. 字幕

- 中文、英文覆盖完整，英文缺失数为 0；
- 两种语言视觉上各自不超过一行；
- 显示文本去掉逗号和句末句号，小数点保持完整，深色底板贴合文字；
- 语义词组完整，没有为单行而切断关键词；
- 字幕不晚于配音出现；允许按语感提前约 0–3 帧，不应明显抢读；
- 所有手工拆分、合并的卡片都单独复查；
- 字幕刷新后，重新检查此前手工修过的时间点。

## 4. 平台安全区

在带平台 UI 的预览中检查：

- 右侧头像、点赞、评论、收藏和分享区；
- 底部账号、作品说明和进度条；
- 中文与英文应作为整体移动，不能只上移其中一条；
- 当前模板可把中文放到评论与五角星图标所在横向区域附近，英文紧随其下；
- 开场、正文和结尾都要分别检查，不能只抽查一帧。

## 5. 最终平台预览

先从 ChatCut 导出预览稿，再放到剪映或带平台 UI 的安全区叠层里检查。若发现字幕太低、人物被挡或书封被裁切，应返回 ChatCut 源工程修改，不在已经导出的文件上二次烧录补丁。

## 6. 可导出条件

只有同时满足以下条件，才报告“可以导出”：

- 时间线实际使用的素材全部在线；
- 开场和正文动效在连续播放中可见；
- 双语字幕完整、同步、语义正确并处于安全区；
- 用户已经确认成片或明确要求导出。

成片通过技术验收不等于会获得流量、成交或平台推荐，不作此类承诺。
