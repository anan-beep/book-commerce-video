# 使用示例

这些是调用方式示例，书名不代表已经完成对应视频。

## 从一本书开始

```text
使用 $book-commerce-video，帮我把《纳瓦尔宝典》做成一条约 90 秒的视频号推荐视频。
我还没有选角度。先核对版本、分析能访问的读者反馈，给我 2–3 个角度。
口播和视觉方案确认后再制作。
```

预期先交版本和研究结果，再确认角度与口播；资料不足时说明缺口。

## 接着已确认口播制作

```text
使用 $book-commerce-video。以下口播已确认，请保持正文。
平台：抖音，画布：1080×1920。请先设计分镜和一张代表性样图。
配音需要把整段文案一次性合成一条音频，不能分句拼接。
最终音频确定后再制作双语字幕和 ChatCut 时间线，先交 15–20 秒样片。
【在此粘贴已确认口播，并提供实际素材位置】
```

预期复用已确认内容，先审核视觉；最终配音是时间轴基准。

## 修复现有时间线

```text
使用 $book-commerce-video，检查我已有的 ChatCut 项目。
只有 01:17 附近的一句字幕明显晚于配音，先定位这句。
保持中英文语义区间一致，检查相邻卡片；不要直接导出。
【提供目标项目和素材访问方式】
```

预期检查目标句及前后时间，只修局部并连续播放验证。
